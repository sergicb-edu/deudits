# M1 — Teclat i normalització d'entrada

## Objectiu
Capturar les pulsacions de teclat del navegador amb latència mínima (< 16 ms), normalitzar `event.code` (tecla física) i `event.key` (caràcter produït, incloent-hi tecles mortes/accents i `AltGr` al teclat català), i associar cada tecla al seu dit segons `content/fingers.json`.

## Contracte
- Tipus i esquemes que ha de respectar: `/contracts/domain.ts` (`KeyEventPayload`, `FingersConfig`, `KeyMapping`, `FingerId`).
- Interfície que ha d'oferir:
  - `resolveFingerForChar(char: string, fingersConfig: FingersConfig): { code: string; finger: FingerId } | null`
  - `normalizeKeyboardInput(rawEvent: { code: string; key: string; timeStamp: number }, expectedChar: string, stimulusTimestamp: number, fingersConfig: FingersConfig): KeyEventPayload | null`
- Què consumeix d'altres mòduls: únicament dades de `content/fingers.json` i tipus de `/contracts`.

## Fitxers que pot tocar
- `/client/src/core/keyboard.ts`
- `/tests/m1-keyboard.test.ts`

## Proves que ha de passar
- Ignora tecles modificadores aïllades (`ShiftLeft`, `ShiftRight`, `AltLeft`, `AltRight`, `ControlLeft`, `CapsLock`, `Dead`).
- Identifica correctament `f` (`KeyF` -> `L-index`), `j` (`KeyJ` -> `R-index`), `ç` (`Backslash` -> `R-pinky`), i espai (`Space` -> `thumb`).
- Calcula la latència `t` en mil·lisegons des de l'estímul.

## Fora d'abast
- No renderitza cap element del DOM ni modifica l'estat de l'exercici (responsabilitat de M2 i M3).

## Criteri d'acceptació
- `npx vitest run tests/m1-keyboard.test.ts` passa al 100%.
